SQL · KPI Manager, KPI "DATA CENTER PUE" 7 lines
GitHub
Select : measurementvalue
From   : measurement
Where  : siteid = 'NORTH' and assetnum = 'DC-ENERGY' and metername = 'PUE'
         and measuredate = (select max(measuredate) from measurement
                            where siteid = 'NORTH' and assetnum = 'DC-ENERGY' and metername = 'PUE')
